# 安全与执行要点

## 环境与编码

脚本使用 ASCII，以兼容 Windows PowerShell 5.1 对无 BOM 文件的读取；中文参数放在 UTF-8 JSON 中。结果显式写 UTF-8。使用 64 位 PowerShell，明确目标用户身份；提权不会自动加载所有用户配置单元。

不要复用大小写不同的变量名，PowerShell 不区分大小写。常量路径用 -LiteralPath，包括名字为 * 的注册表键。Start-Process -ArgumentList 会拼接参数，空格及正则需正确引用；优先在已提权窗口直接调用脚本。

## 目标、预览与备份

PupPattern 只筛候选。删除必须来自已审阅清单，不用短片段或文件名猜测目标。清单路径只允许本地绝对路径，环境变量必须可展开。目录根、Windows 树和重解析点禁止自动删除；遇到共享数据目录先确认所有权。

云同步占位文件也可能带重解析点属性，脚本会保守拒绝这类路径，不将其自动视为普通文件。测试和证据留档使用非同步的本地目录；清理云目录需单独核对提供程序及实际存储范围，不能绕过保护强删。

DryRun 会生成计划副本、日志和结果，但不改服务、任务、注册表值或删除目标。正式操作使用预览时的固定 SHA256。哈希不能代替用户授权；读取完计划到执行之间的并发修改仍需避免，案件目录不应由不可信进程写入。

注册表导出成功且文件非空后才允许对应修改；任务删除前导出 XML。退出码和实际删除结果必须检查，日志中的“准备删除”不代表已完成。文件清理不自动备份，用户数据要另行保存。

WOW6432Node 是视图前缀，不是产品目录。两个视图的共享注册表分支采用统一规则；Policies、Clients 等区域即使列在清单里也不能整树删除。确需处理其中的恶意配置，选择精确注册表值或单独评审的恢复操作。

## 服务、驱动与 Svchost

sc.exe 的 1062 表示未运行、1052 表示不支持停止请求，仅在“停止”步骤视为可接受；停用与删除仍须成功。驱动启动类型不单独决定能否卸载；删除注册不等于已加载驱动消失，需要重启后核验。

Svchost 组成员通常位于父键的同名 REG_MULTI_SZ 值。先核对全部成员均在本次服务清单且停用成功，再删除该值。组子键不会隐式删除，确有恶意叶键时另列清单。不能只删同名子键，不能按非系统组名直接定性。

## 文件占用与重启

删除失败可能来自权限、句柄占用、自保护或路径问题，不能统称“内核保护”。默认记 ERROR。显式启用重启后删除时，先备份 Session Manager 键，保留既有 PendingFileRenameOperations，追加文件再追加从深到浅的目录。登记成功仍为 PENDING，必须重启后证实消失。

路径预检不能完全消除并发替换风险；执行时减少不可信程序活动。不要自动取得整个系统目录所有权或更改广泛 ACL 来强删。

## 取证与结论

首次取证不依赖某一家族特征。常规采集只覆盖当前身份和已加载配置；关键遗漏用手工证据补足。目录时间戳、签名主体、渠道号和 Zone.Identifier 分别解释，不单点定性。同名产品不代表同一版本或本机同一行为。

浏览器 SQLite 数据库如有 WAL，复制主文件可能不是完整快照。采集错误写入状态，无法读取的类别不宣称干净。证据目录需独立保存；临时目录可被清理，不适合唯一留档。

外壳扩展的子键名可能是产品名，CLSID 存在默认值；IconHandler 也可能直接保存 CLSID。解析 COM 时保留用户覆盖与两个视图，32 位 BHO 不能固定读取 64 位服务器。当前用户的 32 位物理 COM 根位于 Classes\WOW6432Node\CLSID，不能套用 HKLM 的兼容别名路径。

原生命令失败可能只返回 stdout 和非零退出码，没有 PowerShell 异常。采集必须检查 LASTEXITCODE，将失败写入本节状态，不用空输出或空错误队列推断成功。

百万级目录不能先全量加载再过滤。目录/哈希探针使用独立工作进程、流式枚举和预算；超时、达到项数或字节上限显示 PARTIAL。部分目录计数是观察下界，不是总数；时间桶也不等于安装次数。详见 performance-forensics.md。

## 出报告与验证

复核必须核对清单目标及发现扫描；未覆盖类别显示 SKIP，查询失败显示 ERROR。清理前证据不能代替清理后验证。报告说明核验范围、残留、待重启、保留软件与证据限制。

手工记录必须有当前阶段、批次、有效时间及案件内非空证据文件。每轮更换 reviewContext.id；final 批次在外部卸载和最后重启后建立。脚本维护 last-mutation.json 并拒绝使用早于最近修改的 PASS，不能删除该记录来绕过时效检查。内容真实性仍需审阅，不将存在文件等同于已完成核验。

Word 输出调用当前可用的文档技能，并按其要求渲染检查。指定的私有公文技能不可用时使用可用替代，不假设其 Node、MSI 或 runtime 存在。
