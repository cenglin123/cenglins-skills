# foxgrep — Foxmail 本地邮件检索工具（7.2 / 6.x / 5.x）

面向 agent 的 CLI 工具：无需密码、无需启动 Foxmail、全程只读，像 `grep` 一样检索本机 Foxmail 邮箱的邮件（主题/正文/收发件人/附件名），并可提取附件文件。

## 位置与运行

```
工具:  foxgrep.py（单文件；语料库为脚本旁的 corpus/ 子目录）
运行:  fg.cmd <命令>       —— 推荐入口，使用内置 runtime\ 的嵌入式 Python，零环境依赖
       python foxgrep.py <命令>   —— 或系统 Python 3（等效）
```

中文输出/嵌入式运行时的编码已由 fg.cmd 统一处理（PYTHONUTF8=1）。

Foxmail 数据目录自动定位（注册表安装路径 → 常见路径扫描），也可用环境变量 `FOXGREP_STORE` 指定。POP3 服务器/账号/密码均自动从 Foxmail 本地账号配置提取，零硬编码。

## 三种数据模式

| 模式 | 数据源 | 覆盖范围 | 时效 |
|---|---|---|---|
| `--live` | Foxmail 7.2 搜索索引（实时直读） | 正文、主题、收发件人、精确时间、附件**名** | 新邮件收进 Foxmail 即可见 |
| `--v6 <根目录>` | Foxmail 6.x `mail\<账号>\*.BOX`（只读扫描） | 正文、主题、收发件人、附件名，**附件内容可提取** | 取决于备份时间 |
| 默认（语料库） | `corpus/*.eml`（Foxmail 批量导出的标准 MIME） | 以上全部 + 附件**内容可提取** | 取决于导出时间 |

模式可混用：例如先 `--live grep` 确认最新邮件，再判断是否需要补充导出；历史归档则用 `--v6` 直扫备份。

### --v6（Foxmail 5.x/6.x）说明

- 用法：`fg.cmd --v6 <安装根或mail目录> <命令>`，支持 list/grep/show/attach/extract/--json
- 原理：BOX 文件是未加密的 RFC822 原文，以 `0x10×7+0x11×6+"S\r\n"` 分隔；工具直接扫分隔符，**不解析 IND 索引**
- 首次扫描建立元数据缓存 `v6cache\*.db`（sqlite；参考：7.5GB / 9365 封约 90 秒），按文件 size+mtime 增量更新，之后秒开
- 邮件跨账号/文件夹统一按日期编号，列表带 `[账号/文件夹]` 标签；JSON 输出含 account/folder 字段
- 会扫到 trash/spam 及已删除未压缩的邮件，属预期行为
- `v6cache\` 为本地可再生缓存，含邮件元数据，**不参与分发**
- 版本适配：7.2 ✓（--live）、7.0/7.1 ✓（--live 自动识别扁平 Data 布局，7.2.25.432 程序+扁平数据样本实测）、5.x/6.x ✓（--v6，5.0 与 6.5.0.29 实测，分隔符相同）

## 命令

```bash
python foxgrep.py [--live] list                    # 邮件列表（编号/时间/收发件人/主题/附件数）
python foxgrep.py [--live] grep <关键词> [-i]      # 全文检索，命中显示上下文片段
python foxgrep.py [--live] show <编号>             # 显示一封邮件全文
python foxgrep.py [--live] attach                  # 附件清单（含所属邮件）
python foxgrep.py extract <编号> [--out 目录]      # 提取附件文件（本地优先：语料库/BOX/匹配副本；本地无副本时自动从 POP3 服务器按主题+日期匹配拉取）
python foxgrep.py fetch                            # POP3 直连服务器拉取新邮件进 corpus（只读不删，自动去重，凭据自动从本地配置提取）
```

所有命令支持 `--json`（放在子命令前）输出结构化 JSON，供程序消费。

注意：语料库模式的编号是按时间重排的 1..N；`--live` 模式的编号是 Foxmail 内部 mailid。两者不同。

## corpus/ 语料库的补充

需要附件内容时，corpus 里必须有对应邮件的 .eml。补充方法（一次性人工操作）：
在 Foxmail 中选中邮件（可 Ctrl+A 全选）→ 右键 → 导出邮件 → 选择 `corpus/` 目录。重名/重复由工具按内容哈希去重。

## 遇到不支持的 Foxmail 版本时（研究任务）

如果你使用的 Foxmail 版本不在适配列表（当前：7.2 / 6.x / 5.x）中，工具可能报错或解析为空。
这时 agent 会启动一次**版本适配研究**，流程如下，你可以放心：

1. **勘察**：只读分析本机 Foxmail 的目录结构、数据文件魔数与邮件边界（方法见 `refs/research-methodology.md`）。
2. **验证**：先小样本解析几封邮件确认正确，再全量扫描并统计失败率。
3. **适配**：若结构可解析，直接修正 foxgrep.py 代码（保持单文件、纯标准库、只读）。
4. **产出**：研究过程中**不会**把任何真实邮件内容、账号、密码写入产出物；
   最终只在 `feedback/YYYYMMDD-<版本号>-<简述>/` 下生成一份**研究报告**（占位化路径）和**代码 diff**。
5. **反馈**：你只需把 `feedback/` 下对应的子目录发回本工具的分发来源（上游），
   上游评审合并后，下个分发版本就会原生支持你的 Foxmail 版本。

研究全程**不修改 Foxmail 任何数据、不破解加密、不经网络外发任何信息**。

## 边界与注意

- **全程只读**：工具不修改 Foxmail 任何数据。
- **附件提取（extract）**：全自动多级兜底——语料库直接提取 → `--v6` BOX 原位读取 → `--live` 匹配语料库副本 → **Foxmail 渲染缓存收割**（邮件被打开/预览过时，附件已被 Foxmail 自行解密到 `Roaming\Foxmail7\Temp-*\Attach\`，无需任何解密）→ POP3 服务器匹配拉取。都未命中时按 `refs/render-harvest-recipe.md` 的渲染收割配方触发一次渲染即可提取。
- `fetch` 走 POP3，服务器地址与凭据自动从 Foxmail 本地配置提取，无需配置；Foxmail 若设置为"收后即删"，服务器上的邮件只短暂停留。
- 邮件内容属于用户隐私数据：不要外发、不要提交到任何仓库。
- `corpus/` 目录包含真实邮件，**不参与工具分发**；分发包含 `foxgrep.py` + `README.md` + `SKILL.md` + `fg.cmd` + `runtime/`（嵌入式 Python）+ `refs/`（版本适配研究方法，供分发机遇到不支持版本时勘察并反馈上游）。
