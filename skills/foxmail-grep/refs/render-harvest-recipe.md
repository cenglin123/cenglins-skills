# 加密库附件出路：可执行流程（2026-11-03 实测，7.2.25.563）

> 一句话：**`--live extract` 失败一次就停**，转「Foxmail 批量导出 .eml → 脚本解附件」。
> 决策树与踩坑细节见 feedback 里的 `report.md`。

## 背景（实测）

Foxmail 7.1+ / 7.2 本地邮件文件**全库加密**（高熵、无 MIME 魔数），附件明文只能由
Foxmail 自身解出。`extract` 的四级兜底在下列条件下**结构性全空**：

- 从未导出过 `.eml`（`_src` 全 None）
- 从未在客户端「保存过附件」（`%APPDATA%\Roaming\Foxmail7\Temp-*\Attach\` 不存在）
- POP3 服务器没有近月副本（收后即删）

此时再重试 `extract` 只是浪费时间。**一次失败即转下面流程。**

> 旧文「单击选中=触发渲染=附件落缓存」已证伪：7.1.3.52 与 7.2.25.563 均实测
> 单击/预览只渲染正文 html，附件不落盘。不要再写「点击触发渲染」的自动化。

## 路径 A（唯一可批量）

### A1. 一次性导出 `.eml`（Foxmail 界面，7 步）

1. 搜索栏右侧下拉箭头 → `+` → 勾选 **时间**（出现 `时间:` 预设下拉）。
2. `时间` 选 **一个月内**（要精确区间用「自定义」，但日期框键盘输入常被忽略，需点日历）。
3. **点结果页标签「所有邮件」** —— 不点只搜当前文件夹（曾误搜成「已发送」）。
4. 列表点首行 → `Ctrl+A`。**校验：预览区显示「选取了 N 封邮件」**（唯一可信选中数）。
5. 右键 → **导出邮件...**（菜单第 10 项，约距光标 +43,+208 px）。
6. 「浏览文件夹」对话框逐级展开 → 选中目标目录 → 确定。
   该对话框没有地址栏；UIA `Expand` 报 0x80070057，**必须 `double_click` 展开节点**。
7. 等「导出邮件...」进度框消失（不要中途操作 Foxmail）。

体量参考：365 封 → 356 个 `.eml` ≈ 3.24 GB，8 分钟；`.eml` ≈ 附件体积 × 1.33。

### A2. 解附件（纯 CLI）

```cmd
py -3 scripts\extract-eml-attachments.py D:\<导出目录>\eml D:\<导出目录>\附件
```

产出 `<日期>_<主题>\<附件名>` 目录树 + `邮件索引.csv`（日期/收发/主题/附件清单），
主题里的非法字符已替换、结尾空格已去除。只读 `.eml`，不联网。

## 路径 B（单封）

预览区右键附件 →「保存全部附件」。只适合一两封。

## GUI 操作纪律

- 路径 A/B 只做最小动作集（多选 → 右键 → 导出/保存），不做配方外的窗口操作。
- **不要用 PowerShell `SendKeys` 驱动 Foxmail**：`SetForegroundWindow` 常被拒绝，
  按键会泄漏到当前前台应用（实测把路径字符串打进了别的窗口输入框）。
  用 UIA 元素 token / 专用 GUI 驱动按元素点击，或先校验 `GetForegroundWindow()`。
- Foxmail 主窗体是 Delphi VCL，标准 .NET UIA `FindAll(Descendants)` 只能看到外壳
  （约 31 个节点）；内层控件需要 MSAA→UIA 桥或专用驱动。
- 窗口「托盘化」时 `GetWindowRect` 高度为 0、截图全白：先 `ShowWindow(SW_RESTORE)`。
- 右键菜单与「浏览文件夹」是独立 HWND，桌面坐标点击常返回 `foreground_unavailable`
  但动作已生效——**以下一步窗口是否出现为成功判据**，不要看返回值。
- 导出的 `.eml` 与保存的附件按邮件隐私同等对待：不外发、不入分发包。
